СТРУКТУРА ПРОЕКТА

Назначение документа

Этот файл описывает, какие папки и файлы потребуется создать для рабочего сайта. Названия можно адаптировать под выбранный стек, но ответственность частей проекта должна сохраниться.

Технические термины простыми словами

Frontend - интерфейс в браузере.
Backend - серверная часть, которая обрабатывает данные и общается с внешними сервисами.
Компонент - отдельная часть интерфейса, например кнопка, поле загрузки или модальное окно.
Маршрут - страница или адрес внутри приложения.
Сервис - отдельный модуль backend для одной задачи, например чтения PDF или проверки Mermaid.
Middleware - промежуточная проверка запроса до основной обработки.
Config - настройки приложения.
Env - переменные окружения, то есть настройки вне кода: ключи, адреса, режим запуска.

Корень проекта

/README.md
Инструкция по запуску, настройке и передаче проекта разработчикам.

/.env.example
Пример файла настроек без реальных секретов. В нем должны быть названия переменных для OpenAI, Jira, Confluence, адреса главной страницы продукта и режимов запуска.

/.gitignore
Список файлов, которые нельзя передавать в Git: реальные настройки, временные файлы, логи, установленные зависимости.

/package.json
Описание команд запуска и зависимостей проекта, если используется JavaScript или TypeScript.

/frontend
Папка frontend-приложения.

/frontend/src
Исходные файлы интерфейса.

/frontend/src/app
Общая настройка frontend-приложения: маршруты, подключение стилей, провайдеры состояния.

/frontend/src/pages/start
Стартовая страница. Отвечает за выбор источника, загрузку файла или записи, ввод ссылки, дополнительные детали, loading-состояние и ошибки из Figma.

/frontend/src/pages/result
Страница результата. Отвечает за отображение схемы, чат, исходный контекст, скачивание, модальные окна и навигацию.

/frontend/src/components
Переиспользуемые элементы интерфейса по Figma.

/frontend/src/components/buttons
Кнопки, включая основную кнопку, кнопки масштаба, отправку сообщения и сервисные кнопки.

/frontend/src/components/inputs
Поля ввода, textarea, поле ссылки, поле сообщения чата.

/frontend/src/components/upload
Компонент загрузки файла и attachment-состояния.

/frontend/src/components/chat
Компоненты AI-чата: список сообщений, кнопки предустановленных запросов, поле ввода, один необязательный attachment в чате, удаление файла до отправки, состояния генерации и ошибки.

/frontend/src/components/diagram
Компоненты просмотра схемы: контейнер Mermaid, масштабирование, перемещение, центрирование, безопасное отображение проверенного результата. Минимальный масштаб - 25%, максимальный масштаб - 200%, шаг кнопками "+" и "-" - 25%.

/frontend/src/components/download
Кнопка скачивания, dropdown, состояния экспорта и ошибки.

/frontend/src/components/modals
Модальные окна "Новая схема" и "На главную".

/frontend/src/components/context
Блоки исходного контекста: файл, запись, ссылка, дополнительные детали.

/frontend/src/styles
Стили интерфейса по Figma: цвета, размеры, сетки, типографика, состояния компонентов.

/frontend/src/api
Клиентские функции для обращения к backend. Здесь frontend отправляет файлы, ссылки, сообщения чата и запросы на экспорт.

/frontend/src/state
Временное состояние текущей вкладки: выбранный источник, введенные данные, схема, чат, масштаб и положение схемы.

/frontend/src/storage
Работа с sessionStorage. Нужна для восстановления состояния после обновления страницы.

/frontend/src/utils
Вспомогательные функции frontend: форматирование размера файла, проверка расширения до отправки, формирование имени скачиваемого файла.

/frontend/src/types
Общие типы данных frontend: источник, результат генерации, сообщение чата, ошибка, параметры схемы.

/backend
Папка backend-приложения.

/backend/src
Исходные файлы серверной части.

/backend/src/server
Запуск backend, настройка API и общих ограничений запросов.

/backend/src/config
Чтение настроек из переменных окружения: OpenAI, Jira, Confluence, адрес главной страницы, лимиты файлов и таймауты.

/backend/src/routes
API-маршруты backend.

/backend/src/routes/generate
Запрос на построение схемы из текстового файла, записи или ссылки.

/backend/src/routes/chat
Запросы AI-чата для изменения уже построенной схемы.

/backend/src/routes/export
Подготовка скачивания PNG, SVG и PDF, если экспорт выполняется на backend.

/backend/src/routes/health
Простая проверка, что backend запущен.

/backend/src/middleware
Промежуточные проверки: размер запроса, тип файла, обработка ошибок, безопасные заголовки.

/backend/src/prompts
Системные промпты. Эта папка должна быть только на backend и не должна попадать во frontend.

/backend/src/prompts/generateMermaid.prompt
Утвержденный системный промпт первоначальной генерации Mermaid из PDF. Его нельзя менять без отдельного запроса.

/backend/src/prompts/editMermaid.prompt
Системный промпт редактирования Mermaid через чат. Текст нужно получить до полной реализации.

/backend/src/prompts/repairMermaid.prompt
Промпт или правило для одной автоматической попытки исправления Mermaid. Нужно подтвердить, если требуется отдельный текст.

/backend/src/services/files
Обработка текстовых и табличных файлов: прием, проверка, определение фактического типа, извлечение данных из TXT, DOCX, PDF, XLS, XLSX и CSV, удаление временных файлов. PDF принимаются только при наличии доступного текста; сканированные PDF без доступного текста не распознаются.

/backend/src/services/recordings
Обработка записей встреч: проверка файла, извлечение аудиодорожки из MP4 и WebM, транскрибация MP3, M4A, MP4 и WebM, удаление временных данных.

/backend/src/services/chatAttachments
Обработка файла, прикрепленного к сообщению AI-чата. Модуль должен принимать один файл до 10 МБ, извлекать данные из TXT, DOCX, PDF, XLS, XLSX и CSV, извлекать аудиодорожку из MP4 и WebM, выполнять транскрибацию MP3, M4A, MP4 и WebM, передавать извлеченные данные как дополнительный контекст текущего сообщения и удалять временный файл после успешной обработки или ошибки.

/backend/src/services/links
Получение данных из Jira и Confluence по ссылке через серверные учетные данные.

/backend/src/services/openai
Обращение к OpenAI для генерации схемы, редактирования схемы и транскрибации.

/backend/src/services/mermaid
Проверка Mermaid-кода, безопасный рендеринг, автоматическая попытка исправления и очистка SVG.

/backend/src/services/export
Подготовка PNG, SVG и PDF без элементов интерфейса.

/backend/src/services/session
Временные служебные данные обработки запроса. Постоянно пользовательские данные здесь не хранятся.

/backend/src/utils
Вспомогательные функции backend: очистка имени файла, проверка URL, сопоставление технических ошибок с пользовательскими ошибками.

/backend/src/types
Общие типы данных backend: источник, результат генерации, ошибка, ответ ИИ, параметры экспорта.

/backend/tmp
Временная папка для файлов во время обработки. Файлы должны удаляться после успешной обработки или ошибки. Эту папку нельзя хранить в Git.

/shared
Общие описания данных, которые нужны и frontend, и backend.

/shared/types
Общие типы запросов и ответов API, чтобы frontend и backend одинаково понимали формат данных.

/docs
Документация для команды разработчиков.

/docs/figma.md
Список Figma-фреймов и соответствующих им экранов или состояний в интерфейсе.

/docs/api.md
Описание backend API простым языком: какие запросы есть, что они принимают и что возвращают.

/docs/security.md
Описание хранения секретов, системных промптов, временных файлов, логов и проверки Mermaid.

/docs/limitations.md
Известные ограничения проекта.

/docs/open-questions.md
Копия или ссылка на список недостающих требований.

/tests
Проверки проекта.

/tests/frontend
Проверки интерфейса: ошибки, loading-состояния, восстановление после обновления, модальные окна, отсутствие системных предупреждений браузера при обновлении, закрытии вкладки и кнопке "Назад".

/tests/backend
Проверки backend: файлы, ссылки, файлы в AI-чате, OpenAI-запросы, Mermaid-валидация, безопасность.

/tests/e2e
Сквозные проверки: пользователь выбирает источник, строит схему, меняет ее через чат, скачивает результат.

/scripts
Служебные команды проекта: локальный запуск, очистка временных файлов, проверка перед передачей.

/public
Статические файлы frontend, если они нужны выбранному стеку.

Что важно не создавать

Не нужна папка для постоянной базы данных пользовательских проектов.
Не нужна папка истории схем.
Не нужен отдельный редактор Mermaid-кода.
Не нужна страница личного кабинета.
Не нужна страница списка проектов.
Не нужна реализация основной страницы продукта.
