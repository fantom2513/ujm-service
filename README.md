# Copilot для Mermaid-схем

Рабочий технический каркас frontend и backend на TypeScript. Реальные OpenAI, Jira и Confluence пока не подключены: для них оставлены контролируемые заглушки и места интеграции.

## Требования

- Node.js 24 или новее.
- Установка зависимостей не требуется: на этом этапе проект использует только стандартные возможности Node.js и браузера.

## Настройка

1. Скопируйте `.env.example` в `.env`.
2. При необходимости измените `APP_PORT`, `APP_HOST` и `PRODUCT_HOME_URL`.
3. Не добавляйте реальные ключи и токены в репозиторий.

## Запуск

Основной переносимый способ:

```bash
node scripts/build.mjs
```

Затем запустить backend, который также раздает собранный frontend:

```bash
node backend/src/server/index.ts
```

Если на компьютере доступен `npm`, можно использовать короткие команды из `package.json`:

```bash
npm run build
npm run dev
```

Если на компьютере доступен `pnpm`, можно использовать:

```bash
pnpm run build
pnpm run dev
```

После запуска сайт открывается по адресу:

```text
http://127.0.0.1:4173
```

Если в `.env` задан другой `APP_PORT`, используйте этот порт.

## Что уже работает

- Стартовая страница.
- Страница результата.
- Навигация между страницами.
- Выбор источника: текстовый файл, запись встречи, ссылка.
- Загрузка одного файла.
- Ввод ссылки и дополнительных деталей.
- Loading-состояния.
- Утвержденные пользовательские ошибки.
- Тестовая Mermaid-схема на странице результата.
- Масштабирование схемы от 25% до 500%.
- Шаг кнопок `+` и `-` 25%.
- Перемещение схемы мышью.
- Автоматическое центрирование.
- Временное состояние через `sessionStorage`.
- Восстановление результата после обновления страницы.
- Dropdown скачивания SVG, PNG и PDF.
- Модальные окна `Новая схема` и `На главную`.
- Backend API для генерации, чата, проверки здоровья и настроек.

## Что пока является заглушкой

- OpenAI-генерация Mermaid: backend возвращает тестовую Mermaid-схему.
- AI-редактирование схемы через чат: API отвечает временным сообщением и не меняет схему.
- Jira и Confluence: backend проверяет ссылку и возвращает контролируемую заглушку вместо реального подключения.
- Транскрибация записей: пока используется заглушка.
- Извлечение DOCX, XLS, XLSX и полноценное извлечение PDF-текста: места для подключения подготовлены.

## API

- `GET /api/health` - проверка запуска backend.
- `GET /api/config` - публичные настройки frontend.
- `POST /api/generate` - построение схемы из файла, записи или ссылки.
- `POST /api/chat` - сообщение в AI-чат. Сейчас временно не меняет схему.

## Важные ограничения

- Системный prompt из PDF не изменен, не скопирован и не отправляется на frontend.
- Реальные API-ключи, пароли и корпоративные адреса не добавлены.
- Постоянная база данных, проекты, история схем, регистрация и личный кабинет не создавались.
- Системные предупреждения браузера при обновлении, закрытии вкладки и кнопке `Назад` не используются.
