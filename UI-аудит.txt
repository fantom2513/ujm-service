Расхождения

1. Экран: Start / Initial / Source=Text file / Empty
Что должно быть по Figma: экран сервиса внутри продуктового интерфейса с верхним меню "UMUX-Оценка / UX Debt / Тепловая карта / CJM / UX-архитектура", breadcrumb "Главная / UX-архитектура", заголовок "Превратите ТЗ в UX-архитектуру", слева одна карточка выбора источника, справа справочная карточка "Что должно быть в ТЗ?" с кнопкой "Построить схему".
Что сейчас реализовано: отдельный dashboard с крупными radio-card слева и формой справа, без продуктовой верхней навигации и без справочной карточки в нужной позиции.
Что нужно исправить: перестроить layout стартовой страницы под две карточки Figma, добавить верхнее меню, breadcrumb, правильные тексты и расположение кнопки.

2. Экран: Start / Source=Text file / File uploaded
Что должно быть по Figma: выбранный источник раскрывается внутри radio-card; upload-компонент горизонтальный, с иконкой файла, названием, размером, зеленым статусом и кнопкой удаления.
Что сейчас реализовано: отдельная большая dropzone с крупной иконкой и текстом.
Что нужно исправить: заменить upload на компактный горизонтальный компонент внутри выбранного источника.

3. Экран: Start / Source=Text file / Loading
Что должно быть по Figma: загрузка отображается внутри кнопки "Построить схему" в правой карточке; выбранный источник остается видимым.
Что сейчас реализовано: loading есть в основной кнопке, но кнопка находится в другой области, форма становится полупрозрачной.
Что нужно исправить: перенести кнопку в правый блок и показать spinner внутри нее без создания отдельного состояния страницы.

4. Экран: Start / Source=Recording / Empty, File uploaded, Loading
Что должно быть по Figma: те же radio-card и upload-компонент, но выбран пункт "Запись встречи", тексты форматов MP3/M4A/MP4/WebM и лимит 100 МБ.
Что сейчас реализовано: запись отображается как отдельная карточка вне основной формы.
Что нужно исправить: привести состояние записи к тому же accordion/radio-card паттерну, что в Figma.

5. Экран: Start / Source=Link / Empty, Filled, Loading
Что должно быть по Figma: выбран пункт "Ссылка на Jira/Confluence"; поле ссылки встроено внутрь раскрытого radio-card; loading снова только в кнопке "Построить схему".
Что сейчас реализовано: ссылка появляется как отдельное поле в правой панели.
Что нужно исправить: встроить input ссылки в выбранную radio-card.

6. Экран: Start / Error states
Что должно быть по Figma: ошибки показываются inline внутри соответствующего компонента: под upload или под input ссылки; отдельного большого красного блока нет.
Что сейчас реализовано: есть общий красный блок ошибки под формой.
Что нужно исправить: убрать общий error-banner и показывать ошибки только в компоненте attachment/link.

7. Экран: Result / Default
Что должно быть по Figma: рабочая область 1440x900; сверху внутри экрана кнопки "На главную", "+ Новая схема", "Скачать схему"; слева узкая панель контекста и чата; справа большая область схемы; zoom-контрол внизу справа.
Что сейчас реализовано: отдельный header с breadcrumb и H1; чат находится справа; схема слева; кнопки растянуты и расположены иначе.
Что нужно исправить: перестроить страницу результата: чат слева, схема справа, верхняя панель как в Figma, без отдельного H1.

8. Экран: Result / Diagram / Zoomed in
Что должно быть по Figma: при увеличении схема остается в правой рабочей области, zoom-контрол показывает процент внизу справа.
Что сейчас реализовано: zoom-контрол сверху слева, схема может выходить из области.
Что нужно исправить: переместить zoom-контрол вниз вправо и сохранить поведение масштаба.

9. Экран: Result / Download / Dropdown open
Что должно быть по Figma: dropdown открывается под кнопкой "Скачать схему", белая компактная карточка со строками PDF, PNG, SVG и иконками.
Что сейчас реализовано: dropdown есть, но размеры, порядок, иконки и позиция отличаются.
Что нужно исправить: привести dropdown к компактному меню PDF/PNG/SVG под кнопкой.

10. Экран: Result / Modal=New diagram / Open
Что должно быть по Figma: фон затемняется, модальное окно компактное; заголовок "Создать новую схему?", текст о том, что текущие данные будут удалены, кнопки "Скачать текущую схему", "Отмена", "Создать".
Что сейчас реализовано: модальное окно крупнее, другие тексты и набор кнопок.
Что нужно исправить: изменить размеры, тексты и набор кнопок без изменения логики подтверждения.

11. Экран: Result / Modal=Go home / Open
Что должно быть по Figma: компактное модальное окно; заголовок "Покинуть страницу?", кнопки "Скачать текущую схему", "На главную", "Остаться".
Что сейчас реализовано: другие тексты и кнопки.
Что нужно исправить: привести тексты и кнопки к макету.

12. Экран: Components / Buttons
Что должно быть по Figma: primary-кнопки темно-синие, secondary светлые, размер компактный, spinner внутри кнопки.
Что сейчас реализовано: кнопки крупнее, часть кнопок растянута на всю ширину, spinner в другой композиции.
Что нужно исправить: обновить размеры, цвета, border-radius, состояние loading.

13. Экран: Components / Upload / Attachment
Что должно быть по Figma: upload - горизонтальная зона с иконкой, текстом и кнопкой; attachment - отдельная строка с иконкой документа, названием, размером, статусом и удалением.
Что сейчас реализовано: upload сделан большой dropzone.
Что нужно исправить: заменить на горизонтальный компонент.

14. Экран: Components / Chat
Что должно быть по Figma: чат расположен в левой панели результата, сообщения и быстрые команды компактные, input закреплен снизу панели.
Что сейчас реализовано: чат расположен справа, быстрые команды выглядят как широкие стандартные кнопки.
Что нужно исправить: перенести чат в левую панель, уменьшить размеры и повторить композицию компонента.

15. Экран: Components / Dropdown / Context Menu
Что должно быть по Figma: белое меню с мягкой тенью, строками с иконками, hover-состоянием.
Что сейчас реализовано: меню без иконок и не совпадает с размерами.
Что нужно исправить: добавить иконки и привести размеры.
